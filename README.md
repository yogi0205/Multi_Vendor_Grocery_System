# 🛒 Multi-Vendor Online Grocery Management System

A web-based application built using PHP (OOP), MySQL, HTML, CSS, and JavaScript that allows multiple vendors to manage and sell grocery products online. This system supports vendor, customer, and admin roles with dedicated functionalities for each.

## 🚀 Features

- ✅ Multi-vendor registration and login
- ✅ Product management for each vendor
- ✅ Customer product browsing and shopping cart
- ✅ Order placement and tracking
- ✅ Admin dashboard for managing users, vendors, products, and orders
- ✅ Real-time order status updates
- ✅ Responsive UI with basic authentication

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP (Object-Oriented Programming)
- **Database:** MySQL
- **Server:** Apache (via XAMPP/WAMP)
